# Preentrega 4 - Sistema de blog

Proyecto realizado para la Preentrega 4 del curso de Python de Coderhouse.

## Descripcion

El programa representa un sistema de blog ejecutado desde la terminal.

Permite:

- Ver todos los posts.
- Buscar posts por titulo.
- Filtrar posts por tag.
- Validar la estructura y los datos de cada post.
- Controlar entradas incorrectas sin cerrar el programa.

## Estructuras utilizadas

- Diccionarios.
- Listas.
- Tuplas.
- Sets.
- Condicionales.
- Bucles.
- Funciones.
- Retornos.
- Validaciones.
- Manejo de errores con `try-except`.

## Ejecucion

Abrir una terminal dentro de la carpeta del proyecto y ejecutar:

```bash
python sistema_blog_funciones.py
```

Luego, seleccionar una opcion del menu ingresando un numero del 1 al 5.
